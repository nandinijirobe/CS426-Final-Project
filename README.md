## About the Game: 
This project was developed for UIC's CS 426: Video Game Design course. The premise of the game is that the  player is a rising celebrity racing through a dense city to audition for multiple top-secret blockbuster films before sunset. However, paparazzi and fans is swarming the streets, and getting caught on camera will cost valuable time. You need to find your way to each audition while also avoiding crossing paths with them.
